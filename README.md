# postroyka-uptime

Внешняя проверка доступности ПоСтройКи каждые 10 минут: сайт, www, манифест
версии приложения, `/health` и `/ready` API. Сертификат проверяется на
соответствие домену.

Работает вне Yandex Cloud: если облако остановит сервер или CDN (как
27.09.2026 при блокировке за неоплату), сообщение всё равно придёт в Telegram.
Пишет только при смене состояния — «упало» и «починилось».

Секреты репозитория: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALERT_CHAT_ID`.
Ручной запуск: вкладка Actions → uptime → Run workflow.
